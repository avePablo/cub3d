# cub3D

## Description

`cub3D` is a 3D raycasting engine inspired by early first-person games.
It renders a navigable maze from a `.cub` map file, parses the scene configuration,
loads wall textures, and displays a simple interactive view using the MLX42 library.

The project focuses on:

- parsing and validating the map and configuration
- building a rectangular playable map
- rendering walls with a raycasting algorithm
- handling player movement and camera rotation
- drawing textured walls, ceiling, and floor

## Instructions

### Requirements

Make sure the following tools and system libraries are available:

- `cc`
- `make`
- `cmake`
- MLX42 dependencies, including GLFW and the OpenGL-related development libraries required by your Linux distribution

### Compilation

From the root of the repository, run:

```bash
make
```

Useful targets:

```bash
make clean
make fclean
make re
```

### Execution

Run the game with a valid `.cub` map file:

```bash
./cub3D map.cub
```

The repository also provides a Makefile target for running with a custom map path:

```bash
make run MAP=map.cub
```

### Controls

- `W`, `A`, `S`, `D`: move the player
- Left and right arrow keys: rotate the camera
- `ESC`: quit the game
